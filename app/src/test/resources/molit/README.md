# 파서 테스트 픽스처

이 폴더의 XML 은 **국토교통부 응답의 구조**를 재현한 파서 단위 테스트용 입력이다.

- 실제 실거래 데이터가 아니다. 단지명은 `파싱테스트아파트` 처럼 실존하지 않는 이름을 쓰고,
  금액·면적도 파서 동작 확인을 위한 값이다.
- 앱 런타임 코드에서는 이 폴더를 참조하지 않는다 (`src/test` 전용).
  화면에 표시되는 값은 언제나 국토교통부 API 응답에서만 나온다.
- 목적은 "필드가 비었을 때 조용히 기본값으로 채우지 않고 실패로 처리하는가" 를 검증하는 것이다.

**주의**: 필드명(`aptNm`, `excluUseAr`, `dealAmount` 등)은 공공데이터포털에 공개된 응답
명세를 따랐으나, 개발 환경에서 data.go.kr 에 접속할 수 없어 실응답으로 검증하지 못했다.
최초 연동 시 실제 응답 한 건과 대조할 것.
